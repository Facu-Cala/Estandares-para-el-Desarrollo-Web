Despliegue en Git Hub 
1. Ingresas a  GitHub y abris repositorio del proyecto.
2. En la barra de herramientas superior, haga clic en la pestaña "Settings".
3. En el menú lateral izquierdo, click en la opción "Pages".
4. Dentro del apartado de configuración "Build and deployment", en la opción "Source" y verifia que esté seleccionado "Deploy from a branch".
5.En el selector desplegable de "Branch", cambie la opción  a al "Brach' a desplegar.
6. Presione el botón "Save".
